# 宇宝饭

你好，这里是我的博客。不定期发布一些内容，主要分为随笔、观点、知识三类。将来如果画了画也会放在这里。

需注意，这里所有观点都是阶段性的，很可能过段时间就被我推翻了。新的想法也会标注进关联博文里以供参考。

主要功能说明：

* 主页下方可以查看活跃日期和最近动向。
* 主页左侧可以联络作者，或点击 RSS 图标订阅最新文章。
* 从 Overview 切换至 Posts 栏可以按时间线查看文章。
* Posts 栏下可按分类或标签筛选文章。
* 最上方左侧可用二字及以上字数的关键词检索文章。
* 最上方右侧可切换日夜两种主题，点一下无障碍小人的图标可调出棕色滤镜、调节字间距和行间距、开启阅读进度条。
* 每篇文章底下带有一个评论区，但用不了。如需讨论可以前往https://github.com/ying-ya-rebirth/ying-ya-rebirth.github.io/issues，点“new issue”按然后开始发言即可。
  * 好心人也可以告诉我gitalk评论区哪里设置得有问题，我求你了🥲
  * 给我发邮件也是完全OK的。

有机会的话想再添加一个图库，来放置照片；更多无障碍功能，包括屏幕朗读、当前段高亮之类的。很快会有一个邮箱订阅更新的功能，省得大家点进我这。

*祝您阅读愉快！*
